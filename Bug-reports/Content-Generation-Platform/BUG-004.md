# BUG-004 – Burger menu button disappears from header during scroll action on mobile viewport

**Priority:** High  
**Severity:** High  

### Description
When performing a vertical scroll-down action on the main page, the global navigation header dynamically changes its background color. During this state transition, the hamburger/burger menu icon completely disappears from the navigation bar, rendering the mobile navigation menu entirely inaccessible to the user.

### Preconditions
User is accessing the platform using a compact/mobile responsive layout viewport.

### Steps to Reproduce
1. Open the platform URL.
2. Verify that the hamburger menu icon is initially visible in the top navigation header.
3. Scroll down the page until the navigation header background shifts to its solid white color state.
4. Observe the right-hand area of the navigation header where the burger menu button was located.

### Actual Result
Upon scrolling down, the burger menu button vanishes completely from the header layout. The user is left with no interactive component to expand the mobile navigation links.

### Expected Result
The burger menu button must remain persistently visible within the global navigation bar at any scroll position on the page, maintaining appropriate color contrast against the modified header background.

### Environment
Web / Chrome / Desktop
