# BUG-003 – Chat welcome message is hardcoded in English and fails to localize (Regression)

**Priority:** High  
**Severity:** Medium  

### Description
A localization regression has been identified in the AI assistant interface, where the initial welcome message ("Hello, how can I help you? 😊") remains static in English regardless of the selected system language. While neighboring UI components (such as the text input placeholder) successfully adapt to localization changes, this specific greeting string fails to translate. *Note: This functionality was operating correctly as of 3 days ago.*

### Preconditions
User has initialized the application layout and opened the AI assistant interface. The behavior is verified across both standard browser sessions and Incognito/Private windows to rule out local caching issues.

### Steps to Reproduce
1. Open the AI assistant chat panel.
2. Observe the default system greeting rendered in English.
3. Locate the localized language selector within the chat interface and switch the language configuration to Georgian.
4. Re-examine the active text elements within the chat interface, specifically checking the initial welcome greeting.

### Actual Result
A localized mismatch occurs: the input placeholder string successfully updates to its Georgian variant ("დაწერე შეტყობინება..."), but the primary introductory greeting message remains hardcoded in English ("Hello, how can I help you? 😊").

### Expected Result
The initial introductory greeting message must dynamically adapt and translate according to the active language state configuration selected by the user (e.g., updating to "გამარჯობა, რით შემიძლია დაგეხმაროთ?" when switched to Georgian).

### Environment
Web / Chrome / Desktop
