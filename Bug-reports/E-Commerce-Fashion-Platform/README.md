# E-Commerce-Fashion-Platform - Bug Reports Portfolio

This repository contains structured bug reports generated during the manual functional and UI/UX testing of a major e-commerce fashion and retail platform based in Georgia. The documentation demonstrates defect identification, precise reporting formatting, and risk evaluation.

The testing scope was dedicated to critical user flows, including product discovery, filtering mechanics, cart operations, and the checkout funnel across various viewports.

## Role
Manual QA Engineer

## Key Findings & Defect Highlights
* **Functional Anomalies:** Identified high-severity bugs within the checkout process and promotional code application that directly impacted conversion rates.
* **UI/UX Inconsistencies:** Logged critical layout shifts (CLS), overlapping text components, and broken containers on responsive mobile viewports.
* **Data Filtering Defects:** Documented edge-case failures in the product catalog where multi-parameter filtering displayed incorrect inventory states.

## Documented Metrics per Bug Report
Every bug report in this repository includes:
* **Unique Defect ID & Title:** Clear, descriptive summary stating the issue, component, and condition.
* **Severity & Priority:** Rated based on business and technical impact.
* **Environment Details:** Browser version, OS, and viewport resolution.
* **Steps to Reproduce:** Strict, sequential steps to guide developers to the exact defect location.
* **Expected vs. Actual Result:** Clear contrast of the system behavior.
* **Visual Proofs:** References to captured screenshots and annotated layout shifts.
