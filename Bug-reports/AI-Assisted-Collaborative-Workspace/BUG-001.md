# BUG-001 – AI chatbot crosses contextual boundaries between distinct project boards causing data leak and inaccurate responses

**Priority:** Critical  
**Severity:** High  

### Description
A major context management vulnerability has been identified within the AI assistant framework. When a user queries the chatbot regarding the visual assets of a specific active project board, the AI model experiences context cross-contamination. It fetches and processes structural metadata belonging to a completely separate, inactive project board (including localized text and embedded media links), returning invalid and leaked information to the user.

### Preconditions
* The user environment possesses at least two distinct, isolated project workspaces created (e.g., Workspace A and Workspace B).
* Each respective workspace contains entirely different visual elements, text configurations, and media nodes on its interactive board.

### Steps to Reproduce
1. Open the platform URL and navigate into the workspace interface for Workspace A.
2. Locate and initialize the AI Chat Panel from the upper-right control header.
3. Submit a direct context-specific prompt to the assistant: "What's on Project1's board?"
4. Evaluate the validation accuracy of the generated AI text response against the actual visual items present on the active board layout.

### Actual Result
The AI chatbot executes a context synchronization failure, returning inaccurate and leaked parameters. It describes structural artifacts, dynamic YouTube video references, and localized Georgian text assets that are exclusively hosted on the separate Workspace B board layout.

### Expected Result
The AI assistant must enforce strict workspace isolation and data boundaries. The model must contextually parse, synthesize, and describe only the specific active board metadata that directly correlates with the user's explicit query and active session workspace.

### Environment
* **Environment Architecture:** STG Staging
* **Hardware Specification:** Lenovo Ideapad Slim 3i (Windows 11 Pro, Build 26200)
* **Browser Specification:** Google Chrome 147.0.7727.139
