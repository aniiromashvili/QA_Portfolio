# BUG-002 – AI chatbot ignores active board context and fails to prompt user for missing details

**Priority:** High  
**Severity:** Medium  

### Description
The AI chat assistant fails to integrate the contextual data models of the active project board into its execution runtime. When directly queried about visible elements, shapes, or structural assets on the current board, the chatbot generates generic conversational placeholders instead of analyzing the board’s metadata. Furthermore, the model lacks a clarification loop, failing to ask follow-up questions when data parameters are insufficient or unretrieved.

### Preconditions
* The user is securely authenticated within the application environment.
* The user account possesses at least one active project workspace.
* The workspace board contains several rendered geometric shapes, text nodes, or visual elements designed for layout configuration.

### Steps to Reproduce
1. Open the platform URL and navigate into the active project workspace.
2. Access the interactive board panel containing the pre-configured geometric elements and figures.
3. Initialize the AI Chat interface by clicking the control action button in the upper-right corner.
4. Submit a context-dependent verification prompt to the assistant: "can you tell me what you see on board of project rn?"
5. Assess the accuracy and specificity of the generated response against the actual visual elements rendered on the active board.

### Actual Result
The AI chatbot generates a highly generic response template that entirely bypasses the real-time context of the active workspace. The model fails to inspect or analyze the geometric properties and figures present on the board. Additionally, when failing to fetch this environmental data, the assistant completely fails to prompt the user with an automated clarification query, returning an irrelevant user experience.

### Expected Result
The AI assistant must programmatically query and process the dynamic context data stream of the active workspace board, generating an accurate itemized response based on the visible elements and shapes. If the board's context vector is structurally inaccessible or provides insufficient parameters, the model must trigger a clarification dialogue loop, explicitly requesting the user to provide further descriptive details.

### Environment
* **Environment Architecture:** STG Staging
* **Hardware Specification:** Lenovo Ideapad Slim 3i (Windows 11 Pro, Build 26200)
* **Browser Specification:** Google Chrome 147.0.7727.139
