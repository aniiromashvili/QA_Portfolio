# BUG-003 – Persistent "Creating folder..." loading spinner hangs indefinitely after successful directory creation

**Priority:** Medium  
**Severity:** Medium  

### Description
An asynchronous UI state management failure occurs when creating a new folder workspace within the application asset library. Although the server successfully processes the request and instantiates the new directory inside the file system layout, the client-side interface fails to terminate the loading state. The "Creating folder..." loading spinner remains active in the interface profile indefinitely, creating an infinite loading loop.

### Preconditions
* The user is securely authenticated within the platform environment.
* The user session is navigated to the asset library or folder management dashboard layout.

### Steps to Reproduce
1. Open the platform application layout and navigate to the directory management interface.
2. Select the core workspace creation trigger action from the control navigation bar.
3. Choose the "Folder" directory entity option from the active dropdown selector options.
4. Input a standard directory string value into the naming field (e.g., "folder 1") and execute the confirmation action.
5. Verify the visual addition of the folder to the user asset list view.
6. Observe the behavior and persistence parameter of the lower system loader graphic.

### Actual Result
The target folder asset is generated successfully and populates inside the active workspace directory index. However, the system fails to clear the interface execution flag; the lower "Creating folder..." pending text indicator and loading spinner persist indefinitely on the active page layout, causing an unhandled UI infinite state lockup.

### Expected Result
Upon receiving a successful server response acknowledgment certifying that the filesystem creation workflow has concluded, the client-side state machine must automatically dismiss and clear the "Creating folder..." loader and spinning element from the current view.

### Environment
* **Environment Architecture:** STG Staging
* **Hardware Specification:** Lenovo Ideapad Slim 3i (Windows 11 Pro, Build 26200)
* **Browser Specification:** Google Chrome 147.0.7727.139
