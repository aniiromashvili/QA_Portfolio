# AI-Assisted-Collaborative-Workspace

This project showcases manual QA testing executed on an AI-assisted collaborative workspace and document management platform. The system allows users to create text assets, organize documents hierarchically into folders, and manage diverse content types.

## Role
Manual QA Engineer

## Responsibilities
* Tested folder management mechanics, validating nested directory structures, creation, deletion, and cross-folder asset migration.
* Performed deep UI/UX and functional testing on text editors and viewing modules to isolate rendering bugs and character encoding issues.
* Validated edge cases in content naming conventions, character limits, and system response to empty states or duplicated titles.
* Conducted cross-browser and screen-resolution testing to ensure font rendering, navigation bars, and layout elements remain visually aligned.
* Logged detailed defects with precise environment details and steps to reproduce, supporting developers in localized fixes.

## Testing Types
* Functional Testing
* UI/UX Testing
* Boundary Value Analysis (BVA) & Negative Testing
* Cross-Browser Testing
* Exploratory Testing

## Tools Used
* Jira
* Chrome DevTools
* Browser-based testing tools
