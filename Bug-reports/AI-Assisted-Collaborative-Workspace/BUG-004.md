# BUG-004 – Existing text content is automatically wiped and input field clears upon clicking text object in Board Workspace

**Priority:** High  
**Severity:** High  

### Description
A severe data preservation defect occurs within the interactive board text component handler. When a user clicks on a previously saved and rendered text object to initialize text editing, the system immediately clears the string value instead of preserving the current data. The entire content is wiped upon focus, forcing the user to re-input the text from scratch. *Note: This behavior is intermittent and was confirmed on one specific project environment while remaining non-reproducible on another.*

### Preconditions
The user has initialized an active project workspace with an empty staging canvas.

### Steps to Reproduce
1. Open an existing project workspace layout.
2. Navigate to the interactive "Board" section view via the core navigation bar.
3. Access the left toolbar architecture, select the "Text" asset object creation trigger, and drop it onto the board canvas.
4. Input a standard text string value and save the asset changes to display the text on the board.
5. Click directly onto the newly generated text object canvas frame once more to re-initialize editing mode.
6. Observe the immediate visual state of the existing text values inside the text editing block.

### Actual Result
Upon capturing focus, the interactive text component completely purges its existing input payload. The text element instantly becomes blank, forcing data destruction, while the formatting control floating toolbar renders over an empty, broken input container.

### Expected Result
Clicking an established text object must trigger standard inline text editing configuration parameters while keeping the existing text payload perfectly intact, highlighted, and fully accessible for incremental modifications without losing prior user data.

### Environment
* **Environment Architecture:** STG Staging
* **Hardware Specification:** Lenovo Ideapad Slim 3i (Windows 11 Pro, Build 26200)
* **Browser Specification:** Google Chrome 147.0.7727.139
