# BUG-005 – Incorrect routing in navigation header loads Games/Projects page instead of News/Blog

**Priority:** High  
**Severity:** High  

### Description
Selecting the "News/Blog" category from the global navigation header dropdown incorrectly routes the user to the "Games/Projects" page layout instead of the actual news stream. As a result, the authentic news content is completely inaccessible to the end user.

### Preconditions
User is on the main landing page.

### Steps to Reproduce
1. Open the platform URL.
2. Hover over or click on the "News" category dropdown in the navigation header.
3. Select and click on the "News/Blog" subcategory option.
4. Observe the loaded page layout and URL path.

### Actual Result
The platform redirects the user to an incorrect destination route, displaying the "Games/Projects" grid module instead of the requested news and blog timeline.

### Expected Result
Clicking the "News/Blog" option within the header dropdown menu must route the user to the dedicated, relevant news content layout.

### Environment
Web / Chrome / Desktop
