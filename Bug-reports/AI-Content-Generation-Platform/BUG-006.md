# BUG-006 – Typography error (Typo) in contact form section title

**Priority:** Low  
**Severity:** Low  

### Description
The main heading text for the interactive feedback form on the "Contact Us" page contains a grammatical error and a typo. Instead of displaying the correct action phrase "Write us a message", the string is misspelled as "Writ us a message", which compromises content quality and design professionalism.

### Preconditions
User is on the main landing page.

### Steps to Reproduce
1. Open the platform URL.
2. Click on the "Contact Us" link in the global navigation header.
3. Scroll down to the middle section of the page where the contact form is located.
4. Observe the spelling and syntax of the form's main section header.

### Actual Result
The form heading displays a visible typo: "Writ us a message", containing a truncated and misspelled word.

### Expected Result
The section heading text must be orthographically correct and cleanly formatted, displaying: "Write us a message".

### Environment
Web / Chrome / Desktop
