# Bug Report: Platform Name Text Invisibility on Content Details Page Due to Background Color Contrast Issue

## Environment Details
* **Device:** Lenovo Ideapad Slim 3i
* **Operating System:** Windows 11 Pro (Version 10.0.26200 Build 26200)
* **Browser:** Google Chrome (Version 149.0.7827.103 / Official Build / 64-bit)
* **Reproducibility Rate:** 100%
* **Testing Type:** UI/UX / Functional Testing

---

## Severity & Priority Matrix
* **Severity:** Medium (Core branding elements are functionally hidden from the user, causing poor user experience)
* **Priority:** High (Directly impacts product presentation and interface consistency)

---

## Component / Module
* Navigation Header / Global Navigation Bar

---

## Summary Description
When navigating from the main landing page to any inner content details page (e.g., specific generated story viewports), the platform brand text located in the navigation header adjacent to the logo component becomes completely invisible. This anomaly occurs because the text element retains a white color style against a solid white header background. The text only becomes readable after a scroll-down action is initiated, which dynamically triggers a CSS class change or background update.

---

## Prerequisites
The tester must be initiated on the main application interface and possess access to individual content item routes.

---

## Steps to Reproduce
1. Navigate to the application staging URL: `https://qa-environment.local/`
2. Scroll to the content library section on the main page and click on any specific story item (e.g., "The Tortoise and the Scorpion").
3. Observe the brand text layout in the global navigation bar immediately upon page load.
4. Perform a vertical scroll-down action on the page and reassess the visibility of the brand text area.

---

## Expected Result
Upon routing to any internal content details page, the platform title text must remain explicitly visible with appropriate color contrast. The text styling should shift to a dark layout tone, maintaining complete visual consistency with the neighboring interactive navigation links.

---

## Actual Result
Immediately after navigating to the internal content page, the platform branding title text disappears as it matches the exact hex code of the header's white background surface. The text becomes structurally visible only after a user scrolls downward, forcing a dynamic header update.
