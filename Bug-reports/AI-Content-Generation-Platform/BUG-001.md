# BUG-001 – Platform name is invisible in header when navigating to inner page

**Priority:** High  
**Severity:** Medium  

### Description
The platform brand text in the navigation header becomes invisible when navigating from the main landing page to any inner content page, as the text color stays white on a white header background. The text only becomes visible after scrolling down.

### Preconditions
User is on the main landing page.

### Steps to Reproduce
1. Open the platform URL.
2. Select and click on any specific story or content item from the main page.
3. Observe the brand text in the navigation header immediately upon page load.
4. Scroll down the page and observe the header area again.

### Actual Result
Upon navigating to the inner page, the platform name text is invisible because it blends with the white background of the header. It only appears after scrolling down.

### Expected Result
The platform name text should be clearly visible immediately upon entering the inner page, using a dark font color similar to other navigation links.

### Environment
Web / Chrome / Desktop
