# BUG-003 – Layout broken on Pricing/Services page when switching to English localization

**Priority:** High  
**Severity:** Medium  

### Description
The visual layout and structural symmetry of the Pricing/Services page completely break when switching the application language from Georgian to English. Unlike the correct Georgian implementation, the English version renders the illustration graphic too large, repositions it beneath the text block instead of the right-hand column, and clips directly into the surrounding content without proper padding.

### Preconditions
User is on the main landing page with the default language active.

### Steps to Reproduce
1. Open the platform URL.
2. Use the navigation header to access the "Pricing/Services" page and observe the correct layout grid.
3. Return to the main landing page.
4. Locate the language switcher in the header and change the localization to English ("ENG").
5. Click on the "Services" link in the English navigation header and observe the page alignment.

### Actual Result
The layout grid breaks entirely under the English localization. The right-hand column area remains empty while the vector illustration scales up excessively, drops directly below the text block, and overlaps with action buttons and content due to missing margins and paddings.

### Expected Result
The page layout under the English localization must maintain absolute visual symmetry and design consistency with the default version. The body text must align to the left, and the proportionately scaled graphic must sit in the right-hand column on the same horizontal plane.

### Environment
Web / Chrome / Desktop
