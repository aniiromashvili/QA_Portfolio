# BUG-002 – UI consistency mismatch in footer layout on Pricing/Services page

**Priority:** Medium  
**Severity:** Low  

### Description
The design implementation of the footer component on the Pricing/Services page deviates from the global footer layout utilized across the rest of the application. Specifically, the alignment and positioning of the social media icons and the corporate branding/logo elements are inconsistent when compared to the master layout.

### Preconditions
User is on the main landing page.

### Steps to Reproduce
1. Open the platform URL.
2. Scroll to the absolute bottom of the main landing page and observe the layout of the footer components.
3. Use the global navigation header to access the "Pricing/Services" page.
4. Scroll to the absolute bottom of the "Pricing/Services" page.
5. Compare the visual structural alignment of this footer against the layout observed on the main page.

### Actual Result
The footer on the Pricing/Services page displays a clear layout mismatch. The lower baseline grid reveals that the positioning of social media icon vectors and the brand identity assets does not align with the structural styling of the other application routes.

### Expected Result
The footer structural layout, component spacing, and asset positioning must maintain absolute visual consistency and uniformity across all internal application pages.

### Environment
Web / Chrome / Desktop
