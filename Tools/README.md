# QA Tech Stack & Tools

This directory provides an overview of the core software testing tools and utilities integrated into my manual quality assurance workflows. It highlights how each tool is practically applied to enhance test coverage, report bugs efficiently, and verify product quality.

---

## Technical Toolset

| Category | Tool | Practical Application & Focus |
| :--- | :--- | :--- |
| **Test Management** | Qase | Designing structured test cases, maintaining test suites, and tracking execution runs. |
| **Defect Tracking & Agile** | Jira | Logging detailed bug reports, managing defect life cycles, and collaborating in Scrum workflows. |
| | ClickUp | Task organization, prioritizing testing activities, and managing sprint backlogs. |
| **Web & UI/UX Testing** | Chrome DevTools | Inspecting frontend DOM elements, validating responsiveness, and analyzing console logs for network errors. |
| **Mobile Testing** | Android Emulator | Executing functional and UI/UX checks across localized virtual mobile environments. |
| **Database Verification** | SQL | Executing basic queries for data validation, backend state checks, and ensuring data consistency. |

---

## Testing Core Methodologies

By leveraging this toolset, my daily testing activities systematically cover:
* **Functional & Regression Testing:** Ensuring new updates do not break existing core application behavior.
* **UI/UX & Compatibility Analysis:** Verifying that visual elements and workflows align perfectly with design requirements across different web and mobile interfaces.
* **Exploratory Testing:** Approaching applications from an end-user perspective to discover edge-case bugs and usability flows.
