## My Testing Approach

- **Risk-Based Testing:** Prioritizing testing efforts on critical business paths to minimize revenue-impacting bugs.
- **User-Centric & UX Validation:** Looking beyond strict requirements to ensure intuitive, accessible, and seamless user journeys.
- **Negative & Boundary Analysis:** Pushing software to its limits by testing edge cases, empty states, and invalid data inputs.
- **Structured Defect Lifecycle:** Writing clean, actionable bug reports that bridge the communication gap between QA and Developers.

### E-commerce & Retail Web Platform
*Inspired by experience with major retail & fashion platforms.*

**Goal:**  
Ensure a flawless and secure user journey from product discovery to successful checkout, protecting conversion rates.

**Key Contributions:**
- Performed end-to-end testing on core business flows (Complex Filtering → Cart Management → Checkout).
- Verified data consistency and visual alignment across responsive layouts using Chrome DevTools.
